로그인됨

자동 로그인이 활성화되어 있어 다음 방문 시 바로 입장됩니다.

1. 스터디 서버 & 방 연결
개인 복습 진도 동기화 테이블 SQL (최초 1회 실행)

Supabase SQL Editor 새 탭에서 아래 코드를 1회 실행하고, Authentication → Providers → Email에서 Confirm email을 끄면 이메일 인증 없이 바로 가입·로그인됩니다. 

create table if not exists public.mc_user_progress (
  user_id uuid not null references auth.users(id) on delete cascade,
  card_id text not null,
  reps int not null default 0,
  interval_days double precision not null default 0,
  ease double precision not null default 2.5,
  due_at bigint not null default 0,
  last_result int,
  updated_at timestamptz not null default now(),
  primary key (user_id, card_id)
);

alter table public.mc_user_progress enable row level security;
drop policy if exists "mc_own_progress" on public.mc_user_progress;
create policy "mc_own_progress" on public.mc_user_progress
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
grant all on table public.mc_user_progress to authenticated;
